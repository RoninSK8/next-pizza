## Стек и библиотеки:

- **Next.js, TypeScript, Tailwind CSS**
- **Prisma ORM + PostgreSQL, NextAuth**
- **React Hook Form + Zod**
- **Zustand, react-use, lucide-react, react-insta-stories**


##### Ключевой функционал:

- Фильтрация товаров с сохранением параметров в URL и SSR-рендерингом
- Добавление товаров в корзину, просмотр в модалке или на отдельной странице
- Авторизация и регистрация через логин/пароль, GitHub, Google
- Подтверждение email при регистрации
- Покупка через YooKassa + письма на почту при заказе и оплате (Resend)
- Редактирование профиля
- Уведомления (react-hot-toast) и индикаторы загрузки (nextjs-toploader)
- Хостинг и база данных — Vercel + PostgreSQL
